# Dragunity · DoomZ · Six Samurai

## Publicar en GitHub Pages
1. Sube `index.html`, `manifest.json`, `icon-192.png`, `icon-512.png` y `sw.js` a la raíz de tu repositorio.
2. En Settings → Pages, publica desde la rama `main`, carpeta `/ (root)`.
3. Abre la URL HTTPS de GitHub Pages en Chrome Android y usa el menú ⋮ → **Instalar aplicación** o **Añadir a pantalla de inicio**.

La imagen que enviaste se utiliza como icono de la app. Las marcas y cartas añadidas se guardan en el navegador. Usa Exportar respaldo para conservar los datos o moverlos a otro dispositivo.

Nota: el sitio incluye los nombres tal como fueron enviados. Algunos nombres de Dragunity estaban incompletos (por ejemplo, “Arrastrar” y “Dr”), y se conservaron sin inventar datos.
