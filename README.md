# Dragunity · DoomZ · Six Samurai

## Publicar en GitHub Pages
1. Sube `index.html`, `manifest.json`, `icon-192.png`, `icon-512.png` y `sw.js` a la raíz de tu repositorio.
2. En Settings → Pages, publica desde la rama `main`, carpeta `/ (root)`.
3. Abre la URL HTTPS de GitHub Pages en Chrome Android y usa el menú ⋮ → **Instalar aplicación** o **Añadir a pantalla de inicio**.

La imagen que enviaste se utiliza como icono de la app. Las marcas y cartas añadidas se guardan en el navegador. Usa Exportar respaldo para conservar los datos o moverlos a otro dispositivo.

Nota: el sitio incluye los nombres tal como fueron enviados. Algunos nombres de Dragunity estaban incompletos (por ejemplo, “Arrastrar” y “Dr”), y se conservaron sin inventar datos.


## Si no aparecen las cartas tras actualizar
- Vuelve a publicar todos los archivos de esta carpeta en la raíz de GitHub Pages.
- En Chrome Android, abre la página, recarga y si sigue mostrando la versión anterior, borra los datos del sitio o desinstala y vuelve a instalar la app. Esta versión usa una caché nueva para actualizar el listado.
- Las listas se muestran en páginas de 40 cartas; usa **Cargar más cartas** para seguir viendo la colección. Buscar y filtrar aplica sobre toda la lista de la colección activa.


Versión v6: muestra numeración consecutiva por carta en cada colección, manteniendo el orden original incluso al buscar o filtrar. También conserva las funciones anteriores.
